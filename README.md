# 错题本 · CuoTiBen

一个完全离线的安卓错题本。拍下作业或试卷，自动按题号框出每一道题，点选要收录的题；之后可以补答案、写解析、标错因，并在「待攻克 / 已掌握」之间管理，按遗忘曲线复习。

> 所有题目图片和整理内容只保存在手机本机的应用私有目录中，不上传、不需要账号。

## 功能

- **拍照收录**：CameraX 相机预览、闪光灯、前后摄切换，也支持从相册导入。
- **自动框题**：使用 ML Kit 中文 OCR 在本地识别题号（`1.`、`（2）`、`三、`、`第 5 题` 等），按题号位置把整页切分成多个题目区域。
- **只认印刷体**：识别前做灰度高对比增强，并按行过滤手写（彩色笔迹 + 笔画/基线/倾斜特征），手写答案不会被当成题目文字；识别不准可一键关掉过滤重新识别。
- **文字可校对**：每道题会保存识别出的题干与选项文字，详情页可直接修改，也可用于全文搜索。
- **语音录题**：没有照片时，直接口述题目和选项，本地 Vosk 模型实时转写并自动整理成题号 / 题干 / 选项 / 答案。
- **选择要收录的题**：点击自动框选区域即可多选；识别不准时可以「手动框选」自己拖拽、缩放选框。
- **备份与恢复**：首页右上角「更多」可导出 zip 备份（题目信息 JSON + 全部题目图片），换机或重装后可导入还原；导入是追加，不会覆盖现有错题。
- **完成状态**：每道错题都有「待攻克 / 已掌握」状态，首页按状态分栏，可一键勾选完成或重新攻克。
- **整理信息**：科目、题号、知识点 / 备注、错因、标签、我的答案、解析 / 正确解法。
- **间隔复习**：今日待复习队列，先回忆再看答案；「还不熟」按 1、2、4、7、15 天再次安排，「掌握了」直接归档。
- **学习统计**：完成率、各科分布、近 7 天收录、错因分布、累计复习次数。
- **细节**：搜索、收藏、分享题目图片、图片双指缩放、编辑自动保存、深色模式。

## 技术栈

| 模块 | 选型 |
| --- | --- |
| 语言 / UI | Kotlin 2.0、Jetpack Compose、Material 3 |
| 架构 | 单 Activity + Navigation Compose + ViewModel + Repository |
| 本地数据 | Room（KSP） |
| 相机 | CameraX |
| 题目识别 | ML Kit Text Recognition（中文，模型内置，离线） |
| 语音识别 | Vosk（离线中文小模型，用户导入） |
| 图片加载 | Coil |
| 图片处理 | BitmapFactory + ExifInterface（自动摆正、压缩、裁剪） |

- `minSdk 26`，`targetSdk 35`，`compileSdk 35`
- 不需要网络权限，没有云服务依赖

## 构建与安装

### Android Studio（推荐）

1. 用 Android Studio 打开本目录 `CuoTiBen`。
2. 等待 Gradle Sync 完成（首次会下载依赖）。
3. 连接手机或启动模拟器，点击 Run。

要求：Android Studio Ladybug 或更新版本、JDK 17、Android SDK Platform 35。

### 命令行

```bash
# Windows
gradlew.bat assembleDebug

# macOS / Linux
./gradlew assembleDebug
```

生成的安装包：

```
app/build/outputs/apk/debug/app-debug.apk
```

用 `adb install -r app/build/outputs/apk/debug/app-debug.apk` 安装到手机。

仓库里已附带一份编译好的调试包：`dist/CuoTiBen-1.0.0-debug.apk`，可以直接安装体验。

> 安装包约 64 MB，主要来自内置的中文 OCR 模型（离线识别题号，首次使用不需要下载）。
>
> 如果 `gradlew` 下载 Gradle 很慢，可把 `gradle/wrapper/gradle-wrapper.properties` 里的
> `distributionUrl` 换成国内镜像，例如
> `https\://mirrors.huaweicloud.com/gradle/gradle-8.9-bin.zip`。

## 语音模型（可选）

语音录题使用 Vosk 离线中文小模型，约 42MB，**不随 APK 打包**，需要手动导入一次：

1. 电脑打开 <https://alphacephei.com/vosk/models>，下载 `vosk-model-small-cn-0.22.zip`；
2. 把 zip 传到手机；
3. 在应用首页点右上角麦克风 → 选择模型 zip，等待解压完成。

模型解压到应用私有目录 `filesDir/vosk-model/`。应用没有网络权限，不会自动下载。不导入模型也能使用「语音录题」页面里的输入框手打题目。

## 使用流程

1. 首页点「拍错题」，拍下作业 / 试卷，或从相册选择。
2. 等待本地识别完成，页面会用方框标出识别到的每一题；顶部「忽略手写」默认开启，右侧会显示过滤掉的手写行数。
3. 点选要收录的题目（可多选）；自动框选不准时点「手动框选」。
4. 点「收录所选题目」，选择科目并保存。识别出的题干和选项文字会一起保存。
5. 打开错题卡片，校对/修改题目文字，补充答案、解析、错因和标签；弄懂后点「标记为已掌握」。
6. 没有照片时，点首页右上角麦克风，口述题目或直接输入文字，保存后同样进入错题详情。
7. 在底部「复习」里按计划回顾，「还不熟」会自动延后再次出现。
8. 在「统计」里查看各科分布与近期收录情况。

## 数据说明

- 题目图片：
  - 原始照片：`filesDir/photos/`
  - 裁剪后的错题：`filesDir/questions/`
- 语音模型：`filesDir/vosk-model/`
- 数据库：Room 数据库 `cuotiben.db`（版本 2，旧版本会自动迁移，新增题目文字列）
- 备份文件：zip 格式，内含 `backup.json` 与 `images/`，只包含本机错题数据
- 卸载应用会清除全部数据；建议定期用「导出备份」保存一份到手机存储或网盘

## 已知限制

- 分栏检测目前只处理单栏和双栏；三栏以上或图文混排时，建议使用「手动框选」。
- 手写过滤是启发式的，刻意偏保守（宁可漏判也不误删印刷体）；黑色手写可能仍会混入，可在框选页关掉过滤后重新识别，或保存后在详情页删改。
- 中文序号（一、二、）会被当作大题标题处理，仅在没有阿拉伯题号时才当作题目编号。
- 首次识别需要加载 OCR 模型，可能要等几秒；语音模型加载也需要 1~2 秒。
- 语音识别依赖口述清晰度和环境噪声，解析出的题干/选项/答案都会放进可编辑输入框，请保存前确认。
